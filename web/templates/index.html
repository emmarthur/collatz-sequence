Help

Rules

  • If n is even, the next value is n ÷ 2.
  • If n is odd, the next value is 3n + 1.
  • Stop when n is 1.

No one has proved that every positive starting number eventually reaches 1, but every number tried so far does. The chart shows how high the values climb before they fall.

Controls

  • Generate builds the full sequence for your starting number.
  • Play walks through the list; Step advances one value.
